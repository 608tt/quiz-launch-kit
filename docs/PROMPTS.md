# 给 AI 的制作提示词

使用方法：复制完整 examples/city.json，再贴下面提示词。生成后导入生成器，结构通过不等于内容通过。

## 第一步：策划（先不要写代码）

> 我要做原创的娱乐性情境测试，主题是【填写】，读者是【填写】。体验应有文学氛围，不使用诊断、算命断言或精准率承诺。先给我 3 个差异明确的产品方向，各包含一句承诺、读者购买动机、结果示例、区别于免费内容的价值、需要核查的事实。选题不得依赖抄袭现有题库。预算是【填写】，我愿意投入【填写】小时维护。

## 第二步：完整题库

> 按我提供的 city.json 格式输出一个纯 JSON 对象，不要代码围栏。保留 version=1。主题【填写】；12 道题；每题 4 项；4 个有明确正反方向的偏好维度；8 个区分明显的结果。每个问题与结果 ID 必须唯一。每个 scores 长度等于维度数量，各数在 -2..2；每个 target 同长度，各数在 -1..1。题目用具体但有意象感的场景，不直接问人格标签。选项没有道德高下、长度相近，排列要交错。结果包含 id/name/tag/target/summary/tension/action/context，后四项写成具体而非通用夸奖；明确娱乐性质。title/subtitle 必须有值；accent/background 为六位十六进制颜色。不能虚构数据、引用或人物生平。城市主题是文学联想；历史人物主题对每个事实在 context 附可靠出处 URL，不确定的删去。不要声称科学量表或自动赚钱。

## 第三步：独立审稿

> 不要为了支持我的方案而夸奖它。审查这份 JSON：1. 题意与权重是否一致；2. 是否几类结果实质相同；3. 是否选项位置暴露计分；4. 哪些描述人人适用；5. 哪些历史或地域断言需要核实；6. 可能缺少哪种偏好的人。逐项提出最小可行修改，不承诺心理学效度。

## 第四步：经营材料

> 基于最终题库写 3 个真实的小红书标题、每篇 6 页图文结构和一份商品详情。价格、题数、有效期、交付形式用我提供的真实参数，缺失参数保留【待填写】，不自行编造销量、用户评价和准确率，不导向站外收款。清楚说明完整交付、试用预览、售后路径与娱乐性质。
