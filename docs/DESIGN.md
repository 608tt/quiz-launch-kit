# 有氛围，也有可以解释的结果

## 1. 先写结果差异，再写题

先写一句产品承诺：“通过 12 个想象场景，给你一张此刻生活偏好的城市意象卡。”承诺的是体验与解释，不是精准预测。

示例有四维，负方向 → 正方向：

| 维度 | 两端 | 实际区分的问题 |
|---|---|---|
| 节奏 | 慢与留白 → 快与推进 | 空闲时间用来恢复还是推进？ |
| 连接 | 独处 → 共同活动 | 怎样的相处方式能补充能量？ |
| 探索 | 熟悉 → 新鲜 | 面对未知倾向靠近还是保留？ |
| 秩序 | 弹性 → 计划 | 变化与可预期性如何取舍？ |

这些是作者定义的编辑维度，不是经验证的量表构念。城市对应是文学创作，不是对居民、地域或真实宜居性的测量。

## 2. 抽象的是场景，清楚的是选择

弱题：“你是内向的人吗？”
好一些：“旅店送你一把钥匙，你希望它打开屋顶、共用客厅、未知街区，还是私人书房？”
但比喻并不能自动增加有效性：试测时追问“你为何选这个”。有人选屋顶是喜欢热闹派对，与你设想的独处相反，就需要改题。

每道题检查：没有明显更体面或更善良的选项；长度相近；不会靠知识储备作答；不要把所有好特征堆在同一选项。正式版本建议交错选项位置，不能长期把 A 写成外向、D 写成自律。

## 3. 算法透明

每个选项给 2–8 个维度各一个 -2 至 2 的数。每维求和，再按这套题所有选项可能的最小/最大总分映射到 [-1,1]。每个结果有同维数 target 向量，以平方欧氏距离最近者为结果。同距离按配置顺序稳定选择；第一、二名距离差小于 0.15 时提示“也靠近”。这个阈值是编辑启发式，不是置信区间。

页面刻度是归一化偏好分，不是百分位或概率。解释区摘录三项权重绝对值总和较大的实际回答，它们只是可供回看的线索，并非完整因果归因或唯一决定结果的题目。

## 4. 每份结果至少四层

- summary：一种具体的偏好，不要“你外冷内热，有时社交有时孤独”这种人人适用的话。
- tension：该偏好的代价或适用条件；不要每类都写成完美人格。
- action：一个轻量、可撤回的小动作，不给重大人生决策。
- context：城市意象的编辑依据；历史人物则补来源、年代与作品信息。

示例不输出“准确率 98%”“天选城市”“命定人格”。也不偷偷随机分配结果。

## 5. 验证感受，而不是制造准感

用同一份答案重复运行，结果必须一致；极端偏好应产生不同结果；检查每类可达性。模拟答题只能验证算法覆盖，不能推断真实人群比例。示例的 15,000 次固定种子模拟已检查八类可达，未要求均匀分布。

试测问三题：哪句话对应你？哪句话不对应？哪道题你按不同于作者预期的意思理解？记录原话，不只问“准不准”。让被试盲选自己的报告与另一份报告；如果都同样喜欢，结果差异可能不足。这是编辑试测，不等于科学量表验证。
