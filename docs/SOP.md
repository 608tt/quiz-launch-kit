# 从选题到交付的七步 SOP

这是可执行的工作流，不是收益保证。研究和规则来源见 [RESEARCH](RESEARCH.md)。每一步都留下一个能检查的产物，再进入下一步。

## 1｜看需求：1 页选题卡

在小红书用“城市 测试”“历史人物 测试”“趣味 测试”等关键词观察 10–20 条公开内容。记录日期、链接、标题结构、公开价格、交付描述、评论中的疑问。不要把点赞或营销号销量当成已验证利润；不要复制他人整套题库、报告或图片。

选题卡填写：谁在什么时刻想做？结果适合拿来分享什么？用户为何不直接看免费帖子？交付是否超出一句标签？你能不能独立完成并长期维护？先选一个主题。示例方向是“生活节奏的城市意象”，不要一开始做心理疾病筛查、专业诊断或重大择业建议。

## 2｜做产品：题库 + 一份完整报告

按 DESIGN/PROMPTS 先做结果差异与维度，再写 12 道情境题。首版至少有一句概括、一处偏好代价、一项行动、实际回答线索、保存卡片。用生成器导出，完整走一遍。为主题更换题库与配色，不只换名字。

## 3｜试测：10–20 人反馈表

这是建议的编辑试测规模，不是统计效度样本。邀请愿意反馈的人，先说是娱乐测试。记录耗时、卡住的位置、最贴切/最不贴切的句子、对结果差异的理解、是否愿意以某价购买及原因。意愿不等于真实支付。可用匿名编号；不收身份证、生辰、详细住址或健康信息。

验收：全部题可答、返回不重复计分、结果不是随机、每类可达、导出不乱码、手机不横向溢出、弱网入口能打开、题库无抄袭与史实错误。重大故障先修，不用更多笔记掩盖体验问题。

## 4｜定价与上架：先确认能卖什么

进入自己的商家后台，核对账号主体、可用类目、测试服务/电子资源是否允许、自动发货能力、外部履约网址是否许可，以及当前售后规范。**公开规则不能证明你的具体类目一定准入。** 不确定时向平台咨询并保存答复；不可用时暂停收费，可先做免费产品验证。

填写商品页：真实题数、完整结果内容、适用设备、娱乐性质、价格、发货形式、兑换截止、兑换后使用期、设备变更处理、退款与失效处理。0.99 元只是候选价格；算完成本再选，不写“永久”“无限次”而交付只有 24 小时。

## 5｜接交付：用一单走通

如果平台允许该商品及履约方式：商家后台配置平台认可的自动发货或服务市场工具 → 上传一次性码库存 → 每单发唯一兑换码及获准使用的入口 → 买家兑换 → 使用 → 售后。码服务不接支付、不自行判断付款。不要把口令当订单校验，不在笔记中引导站外收款。

没有自动发货能力且类目要求自动发货时，不用手工私信绕开要求。开发环境可以手工演练；正式销售以平台要求为准。真实测试订单涉及付款，由经营者自己执行。

端到端演练：未付款无兑换码；一单一码；两个人同时兑换同一码不能都成功；网络失败能查订单补发；撤销旧码后旧会话失效；新码正常；换设备路径与商品承诺一致。服务器参考版只能做基础验证，上线前按 DELIVERY 补监控、HTTPS 与备份。

## 6｜发布：三种内容角度

从 CONTENT 选择一套：情境体验 / 结果差异 / 产品制作过程。使用真实界面和自己的体验。能挂商品组件时按规则使用；不要“评论暗号领链接”、二维码站外收款或谐音绕规则。封面写一个清楚的问题，不塞满卖点。

一次只变化一个变量：同主题试两种标题或封面；记录曝光、点击、订单、退款、客服耗时，不把微小样本差异当确定规律。不批量刷屏、不伪造评价。

## 7｜复盘：每周一张漏斗表

有曝光没点击：先审标题是否让人理解；有点击没购买：看预览、价值与价格；买了不完成：修访问、题意和长度；完成但退货：核对承诺差距。更换一个环节再测。

停损例：预设一周最多投入 6 小时、推广支出 0 元，这是个人实验预算，不是平台最佳阈值。到期仍只有收藏、没有真实需求，先访谈并改定位；不要为了回本扩大支出。只有每单贡献为正且交付稳定，才考虑扩大。
