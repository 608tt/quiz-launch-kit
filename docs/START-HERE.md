# 第一次做出自己的测试

目标：先得到能从头做完、结果可保存的 `quiz.html`。先不买域名，不开广告。

1. 仓库首页点绿色 **Code → Download ZIP**，解压到一个文件夹。
2. 双击根目录 **studio.html**，建议用桌面 Chrome/Edge。它是已构建的离线版本。不要双击开发入口 index.html。
3. 先在右侧完整做一遍城市示例，查看结果与自己的选择是否一致。
4. 左侧改标题和一句邀请，选择“湖岸 / 旧信 / 夜航”配色，点“更新试玩”。
5. 要换主题，打开 examples/city.json 作为格式样板，把它与 [提示词](PROMPTS.md) 交给你常用的 AI。只修改标题并不会改变计分或结果。
6. 把 AI 返回的纯 JSON 存为 UTF-8 的 `.json` 文件；可在“编辑完整题库”中直接替换文本。点“校验并应用 JSON”。错误会显示原因，不会自动覆盖成功的配置。
7. 人工检查每个结果的名称、描述、反例、建议和背景。历史人物主题必须核查史料，不能把 AI 编的引语当史实。
8. 点“保存题库 JSON”，保留一份配置；点“导出独立网站”，得到 `quiz.html`。它包含所有代码与题库，可以直接双击打开，也可部署到合适的静态托管。
9. 用另一浏览器打开导出文件，做完、返回修改、重测、保存 PNG、打印 PDF。手机浏览器需额外实测，尤其微信/小红书内置浏览器的下载行为。
10. 邀请 10–20 人试测，不先透露想要的结果。通过 [验收单](SOP.md) 再决定是否收费。

生成器不联网调用 AI；导入与答案处理在浏览器内完成。题库没有自动持久化，关闭前请保存 JSON。切换配色/更新预览会重置答题。

## 常见问题

- JSON 报错：检查中文引号、最后一个逗号、分值维度数量；不要带 Markdown 代码围栏。
- 导出的页面无法打开：确认后缀是 `.html` 而不是 `.html.txt`，从下载文件夹打开。
- 想改结果数量：在 results 增删，允许 2–24 个；问题 4–40 道，每题 2–6 项。
- 想做历史人物：重新写问题、结果和权重；不要把城市名替换成人名就声称完成了新测试。
- 想直接收费：静态文件可以被复制；看 [交付路线](DELIVERY.md)，不能往 JS 中塞一个通用密码冒充付费验证。
